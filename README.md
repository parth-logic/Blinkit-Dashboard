# 🛒 Blinkit Sales Dashboard

An interactive Power BI dashboard that analyzes sales performance for Blinkit, an Indian quick-commerce grocery platform. It covers item categories, outlet types, and customer satisfaction.

![Dashboard Snapshot](snapshot%20of%20Blinkit%20Dashboard.png)

## 📌 Objective
Find out which products, outlet types, and locations drive revenue, and where there is room to improve sales and customer ratings.

## 📊 Key KPIs
- **Total Sales**
- **Average Sales per Order**
- **Number of Items Sold**
- **Average Customer Rating**

## 🔍 Analysis Covered
- Sales by Item Type
- Sales by Fat Content (Low Fat vs Regular)
- Sales by Outlet Establishment Year
- Sales by Outlet Size and Location Tier
- Sales by Outlet Type
- Outlet-wise metrics: Sales, Items, Avg Sales, Rating, Item Visibility

## 🛠️ Tools Used
- **Power BI** – data modeling, DAX measures, visualization
- **Excel** – source data
- **Power Query** – data cleaning and transformation

## ▶️ How to Use
1. Download the repo.
2. Open the `.pbit` file in Power BI Desktop.
3. When prompted, point it to `BlinkIT_Grocery_Data.xlsx`.
4. Explore the dashboard with the slicers and filters.
